### LLM helper (llm)
Calls a language model and returns text. Each call has fresh context: no chat history, earlier helper results, or parent tools. Supply all necessary input. The model defaults to the current chat's model.

- Python: await llm(text, system="Return one label: positive, negative, or neutral.")
- JavaScript: await llm(text, { system: "Return one label: positive, negative, or neutral." })
- Optional settings: model (model ID), system (instructions), effort (none, minimal, low, medium, high, xhigh). Omit effort unless an override is needed and supported by that model.

Use this for language processing within a larger pipeline, such as classifying records or summarizing extracted text. Put fixed instructions in system and the data in the prompt. The result is model-generated text, not independently verified evidence or guaranteed schema-valid JSON. Avoid an extra call for work you can answer directly.
