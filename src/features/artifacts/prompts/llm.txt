### LLM helper
Use llm for language processing inside a pipeline; handle direct answers yourself. Returns text with fresh context: no chat history, earlier helper results or parent tools. Supply all inputs; put fixed instructions in system and data in the prompt. Validate generated JSON and factual claims.

- Python: `await llm(text, system="Return one label.")`
- JavaScript: `await llm(text, { system: "Return one label." })`
- Bash: `cat input.txt | llm -s "Summarize" > summary.md`. Prompt arguments and stdin are combined. Flags: -m/--model, -s/--system, -e/--effort, -o/--output; use -- before dash-prefixed prompts.

Optional model defaults to the chat's model. Optional effort: none, minimal, low, medium, high, xhigh, max; omit unless a supported override is needed.
