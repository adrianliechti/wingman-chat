## Binary documents
Uploaded Office/PDF/email artifacts retain their original bytes. Use the Python runtime to inspect or modify them:
- DOCX: docx (python-docx), docx2txt.
- PPTX: pptx (python-pptx).
- XLSX: openpyxl, xlsxwriter, pandas.
- PDF: reportlab for creation; pypdf for merging/splitting; pdfminer for prose/layout; pdfplumber for tables. For borderless tables, try text-based vertical/horizontal strategies or inspect extracted text.
- MSG: extract_msg. EML: standard-library email.parser.
- Charts for embedding: matplotlib/seaborn, saved as PNG or SVG.

When an applicable format skill is available through read_skill, read it before building that deliverable. Save outputs under /home/user/ with the requested extension.

There is no LibreOffice, Pandoc, pdftoppm, markitdown, or external recalculation command. openpyxl does not calculate formulas; missing cached values do not justify replacing formulas with constants. Use native list/numbering APIs in Office files. Preserve existing formatting when making localized changes.
