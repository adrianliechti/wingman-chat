## Code execution
Use execute_script: Python for data, computation and documents; JavaScript for browser media and rendering; Bash for shell pipelines. For small interactive replies in chat, use inline UI. Use HTML artifacts for requested interface files or needs beyond inline components; interpreter scripts have no DOM.

Pass code with language, or path to an artifact/selected-skill script. Optional args is an array of strings, excluding the script path.

Only workspace files persist between runs; import what each run needs. Successful runs commit file changes atomically; failed runs discard them. Read failure output and hints before retrying. Print concise results (32 KiB output cap); save large results as files. Use files to pass data between runtimes.

Python/Bash work in /home/user/: artifact /data.csv is /home/user/data.csv. JavaScript uses artifact paths directly. Repository files are not mounted. Selected skill resources are under skills/<name>/ in each workspace; treat them as read-only and save outputs elsewhere. Reuse known paths; inspect unfamiliar data before transforming it and verify results against source data.

Python:
- Python 3.14 / Pyodide, NumPy 2.x, pandas 3.x. Static imports load bundled offline packages, including imports in local modules. For other dynamic imports, explicitly import the package to preload it. pandas preloads its Excel, Parquet and Markdown engines.
- Available: numpy, pandas, pyarrow, duckdb, scipy, sklearn, statsmodels, sympy, matplotlib, seaborn, PIL, cv2, openpyxl, xlsxwriter, docx, pptx, pypdf, pdfminer, pdfplumber, reportlab, and the standard library. Polars is unavailable.
- No network, host shell/subprocess programs or package installation. Use top-level await, not asyncio.run/run_until_complete.
- File scripts support __file__ and sibling imports; relative I/O still resolves from /home/user/.
- DuckDB 1.5 sees workspace files. Use `with duckdb.connect() as con:` and `con.register(name, df_or_arrow_table)`. In-memory tables end with the run; prefer Parquet outputs for previews and dashboards. Connections default to 256 MB and one thread.
- DuckDB has no INSTALL/LOAD or read_xlsx: read Excel with pandas and register the frame. `rel.arrow()` returns a reader; use `rel.to_arrow_table()` for a Table, `rel.to_arrow_reader()` or COPY for large results.
- Matplotlib is headless: use savefig, not show. Write Arrow IPC uncompressed when JavaScript will read it.

JavaScript:
- Web Worker: browser APIs, no DOM, Node, module imports or remote network. Globals: arrow, mediabunny, echarts, jsPDF, Buffer and a minimal process shim.
- Files: vfs.read/readBytes/readJSON, vfs.write/writeBytes/writeJSON, vfs.list/exists/remove. vfs.write accepts strings or bytes and optional contentType. Local fetch reads VFS.
- File scripts expose __filename/__dirname as artifact paths. Use top-level await; console.log or return produces output.
- Render with OffscreenCanvas or `await svgToPng(svg, {width, height})` (PNG bytes).
- Arrow JS handles IPC, not Parquet; use Python for Parquet. Use BigInt for exact 64-bit integers.

Bash:
- Virtual shell with pipelines, redirects, loops, functions, cat/grep/sed/awk/find/jq and file operations. No network, host binaries, installation or Python/Node commands; invoke execute_script in the appropriate language instead.
- `llm` and configured `ocr`/`extract` commands use app services; see helper instructions.
- Use `$0`/`dirname` for adjacent script resources; BASH_SOURCE is unreliable. args becomes positional parameters without shell interpolation.
- A nonzero final exit discards file changes. Use `set -e` and `set -o pipefail` to stop on earlier failures. Results include stdout, stderr and failure status.
