### SQL over workspace data (DuckDB)
Every CSV, TSV, JSON, JSONL/NDJSON, Parquet, Arrow and XLSX artifact (also `.gz`-compressed text files) is queryable by name in DuckDB, which runs in the browser: `SELECT region, SUM(amount) AS total FROM 'data/sales.csv' GROUP BY region` (the bare file name also works when it is unique). Spreadsheets: `SELECT * FROM read_xlsx('report.xlsx', sheet = 'Sheet1')`. The excel, fts and icu extensions load on demand. Results are plain JSON: `{ columns: [{ name, type }], rows: [{ … }], rowCount }`.

- Dashboards and explorers over workspace data must query DuckDB at runtime for every filter and view. Never embed a copy of the dataset (or precomputed aggregates) in the page or a companion script when the file is in the workspace; the current `duckdb_files` list in the request context names what is queryable.
- In HTML artifacts: `const conn = await wingman.duckdb.connect(); const { rows } = await conn.query(sql, params?); await conn.close();` — or `wingman.duckdb.query(sql, params?)` on the page's default connection. `wingman.duckdb.files()` lists the mounted names. Prefer SQL over hand-written aggregation for dashboards.
- In both interpreters: `await sql(query, params?)` returns the same shape (Python: a dict; `pandas.DataFrame(result["rows"])` when a frame is needed). SQL calls share a session within one run; tables and session state end when the run finishes. Files written during the current run become queryable in the next run.

Each HTML document owns its SQL session until navigation or close. Results are limited to 100,000 rows and 16 MiB; use aggregation, LIMIT and pagination for larger datasets. The engine has a 256 MB memory budget and operations time out after two minutes.

Dashboard pattern:
```
const w = window.wingman;
if (w?.capabilities.duckdb) {
  const { rows } = await w.duckdb.query("SELECT region, SUM(amount) AS total FROM 'sales.csv' GROUP BY region ORDER BY total DESC");
  echarts.init(document.getElementById("chart")).setOption({ xAxis: { type: "category", data: rows.map(r => r.region) }, yAxis: { type: "value" }, series: [{ type: "bar", data: rows.map(r => r.total) }] });
}
```
