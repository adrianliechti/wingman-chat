### Translation
Configured languages and file formats vary. All calls are async:
- Python/JavaScript: `await translate(text, lang)` returns text.
- Python: `await translate_file(input, lang, output)`.
- JavaScript: `await translateFile(input, lang, output)`.

File calls preserve format, write output and return its path. Send whole texts/files to retain context and formatting; split only for service limits and preserve order/terminology. For same-language style rewrites, answer directly or use llm in a pipeline.
