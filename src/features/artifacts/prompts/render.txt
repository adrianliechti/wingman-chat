### Image rendering helper
render generates imagery or edits supplied images through the configured remote service. Await it; it writes output and returns its path.

- Python: `await render(prompt, output, input=paths, aspect_ratio="16:9", quality="high", background="transparent")`. input is an optional path or list; controls are optional keyword-only arguments.
- JavaScript: `await render(prompt, output, paths, { aspectRatio: "16:9", quality: "high", background: "transparent" })`. paths is an optional array; use [] before options when generating without references.

Controls: aspect ratio; quality low/medium/high (xhigh/max where supported); background transparent/opaque. The service maps supported values and ignores unsupported controls.

Use for photos and illustrations. Generate or revise data charts and diagrams with plotting libraries from their source data.
