### OCR helper (ocr)
Extract text and layout from scanned PDFs, document images, or Office files through the configured remote service.

- Python: text = await ocr("/home/user/scan.pdf")
- JavaScript: const text = await ocr("/scan.pdf")

For ordinary text PDFs and Office documents, try local extraction first using the document libraries. Use OCR when the user requests it, the document is image-based, or local extraction misses or garbles relevant content. Judge coverage and readability; a short but valid text is not evidence that extraction failed. Mixed documents may need OCR even when some text extracts correctly.

Read images already included in the message directly when that suffices. Use OCR for precise transcription or batch extraction; use vision, when available, for visual interpretation.

Pass the whole document in one call by default. Follow actual service limits or errors if a smaller input is required; avoid a separate network call per page.
