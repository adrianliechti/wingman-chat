Launch one agent to handle a bounded task in a separate context. The agent has access to the supplied tools and runs its own sequential agentic loop. Only its final result is returned, keeping your context clean.

When to use:
- Research tasks requiring many tool calls (exploring artifacts, finding all usages, multi-step lookups).
- Independent subtasks whose intermediate results would clutter your context.
- Multiple agent calls from one response are executed serially by this runtime; do not promise parallel execution.

When NOT to use:
- Simple tasks needing 1-2 tool calls — just use the tools directly.
- When the user needs to see intermediate results — they won't be visible.

Prompting tips:
- The agent has NO access to your conversation history. Write the prompt as a self-contained briefing.
- State the goal, constraints, relevant context, and output contract. Avoid prescribing an unnecessary process. Distill the result to what is actionable when relaying it.
