Delegate a bounded task to a child agent with the supplied tools. In chat, the child receives the conversation at the point of delegation and streams its work in a separate card; its result returns to the parent. Voice receives the child's final result.

Use this for substantial research or independent subtasks. Handle simple tasks with the tools directly. Provide a clear brief with the goal, constraints, relevant context, and expected result. Avoid overlapping writes to the same workspace files when delegating multiple tasks.
