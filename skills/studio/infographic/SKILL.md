# Infographic

Extract the central message and supporting facts from the conversation/workspace. Verify numbers, units, dates and sources before composing. Select enough material to support the message at the requested size; do not invent statistics or force a fixed number of points.

Use the requested format, normally PNG for a shareable image. Choose a visual structure that explains the subject: comparison, timeline, map, process, annotated object or chart. Match the source brand and desired style. Let hierarchy distinguish the main finding from supporting evidence.

Use deterministic drawing/typesetting for exact copy, numbers and quantitative chart marks. Generated imagery can supply a useful illustration, texture or background; it is optional, not a requirement for every infographic. Reserve space for the text layer when generating. Do not use an image model to establish numerical accuracy.

For a raster composition, measure and wrap text with Pillow, use available fonts, preserve image aspect ratios and include concise source lines. For vector output, author SVG or use plotting tools for data geometry. Use `data-visualization` when chart validity requires deeper analysis.

Check every displayed value against its source, including denominators, percentages and rounded totals. Inspect the final image at its intended viewing size for clipping, hierarchy and legibility. Save the deliverable and name any interpretation or data gap that changes its meaning.
